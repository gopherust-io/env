# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.6.x   | Yes       |
| 0.5.x   | Yes       |
| < 0.5   | No        |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately via one of:

- GitHub Security Advisories: **Security → Advisories → Report a vulnerability** on [gopherust-io/env](https://github.com/gopherust-io/env)
- Email the maintainers listed in the repository profile / org contacts

Include:

1. Description of the issue and impact
2. Steps to reproduce or a proof of concept
3. Affected versions / commit if known

We aim to acknowledge reports within **7 days** and to provide a fix or mitigation timeline after triage.

## Disclosure

We prefer coordinated disclosure. Please give us a reasonable window to ship a fix before public discussion.
